## API surface

**An API exists and is completely gated.** Centrical publishes no public developer portal, API
reference, OpenAPI/Swagger definition, GraphQL endpoint, MCP server or A2A agent card — but two
independent public signals confirm a production API:

1. **`https://api.centrical.me`** is a live AWS API Gateway custom domain
   (`d-zs53r91md7.execute-api.us-east-1.amazonaws.com`). Every anonymous request is rejected by the
   API itself with `403 {"message":"Forbidden"}` and `x-amzn-errortype: ForbiddenException`; paths
   under `/v1/` return `{"message":"Missing Authentication Token"}`. Those are an API refusing a
   caller, not a missing host.
2. **Centrical's own status page names the API as a production component.** A "Core Api" component
   is listed in all three regional groups (North America, Europe, APAC), and the "Web Application"
   component is described by Centrical as "Front End, Admin Console and **Management API**".

The technical documentation for those interfaces is available to contracted customers only, through
the Zendesk help center at support.centrical.com, which is sign-in gated.
